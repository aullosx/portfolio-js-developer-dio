Este é um projeto de portfólio desenvolvido como parte do bootcamp da [Digital Innovation One (DIO)](https://web.dio.me/), com foco em habilidades de desenvolvimento front-end utilizando HTML, CSS e JavaScript.

## 📸 Visão Geral

O projeto consiste em uma página de portfólio pessoal que apresenta:

- Foto de perfil
- Nome e título profissional
- Informações de contato
- Seções para projetos, habilidades e redes sociais

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3 (com Grid e Flexbox)
- JavaScript Vanilla
- Git e GitHub Pages
